# Pokemon-Legendary-Classifier

## 🎯 Motivation 
Since childhood, Pokémon has been one of my favorite game franchises. As new generations continue to be released, I began to wonder how artificial intelligence could be combined with Pokémon data. This project explores the possibility of using machine learning techniques to identify and predict Legendary Pokémon, while also investigating methods for generating entirely new Pokémon concepts.

## 👾 Project description
The goal of this project is to apply fundamental Exploratory Data Analysis (EDA) techniques to uncover patterns, relationships, and insights within Pokémon data. These findings will be used to develop a Pokémon Legendary Classifier using both supervised and unsupervised machine learning approaches, including algorithms such as K-Nearest Neighbors (KNN) and Multiple Linear Regression.

The dataset used in this project is the Pokémon dataset available on Kaggle, which contains information on all Pokémon up to the eighth generation, including their base statistics and characteristics. The image below illustrates an example of a Pokémon's stats, which serve as the features used to train our models.

![image alt](https://github.com/Alaninja1209/Pokemon-Legendary-Classifier/blob/ba966862ec8bfb261d6827abed7f1192104b7c8e/images/Kanto_Starters_Stats.png)

Furthermore, we explore the use of Natural Language Processing (NLP) and Generative Adversarial Networks (GANs) to generate new Pokémon concepts from simple text prompts such as fire, tail, or dragon. This approach demonstrates how generative AI can transform natural language descriptions into unique Pokémon-inspired creations.

## 🚀 Getting started, requirements before starting
Before getting our hands dirty, make sure to have the next requirements:
- Install a Python version above 13.3.0, and the following libraries: Numpy, Seaborn, Pandas, Matplotlib, Pytorch and TensorFlow
- Download the Pokemon Dataset from Kaggle
